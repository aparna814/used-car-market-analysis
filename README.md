# Used Car Market Analysis

## Project Overview
This Excel-based data analysis project explores trends in the used car market using data cleaning, pivot tables, charts, and business insights.

## Objectives
- Analyze car prices across manufacturers
- Study the impact of mileage on price
- Identify fuel type trends
- Examine year-wise price patterns

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Visualizations
- Data Cleaning

## Key Insights
- Price varies significantly across manufacturers.
- Mileage has an impact on resale value.
- Newer vehicles generally command higher prices.
- Fuel type influences market pricing trends.
